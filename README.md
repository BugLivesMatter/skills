# Навыки для Codex

## reports

Написание и оформление учебных работ по разным предметам в DOCX и PDF:
Times New Roman 14, выравнивание текста по ширине, таблицы с сеткой,
читаемые графики и подписи рисунков. Приложения появляются только по запросу.
Правила собраны в [reports/SKILL.md](reports/SKILL.md).

Внутри одного устанавливаемого навыка разделены три режима:

| Режим | Что определяет |
| --- | --- |
| [Обычный отчет](reports/guides/modes/report.md) | Компактная структура лабораторных, практических работ и отчетов по практике |
| [Курсовая](reports/guides/modes/coursework.md) | Цель и задачи, связные главы, содержание, обоснование решений и результаты |
| [Диплом / ВКР](reports/guides/modes/thesis.md) | Доказательность, собственный вклад, проверка результата и требования программы |

Верстка у режимов общая. Ее основа — отдельно изученная эталонная
курсовая; [разбор оформления](reports/guides/reference-style.md) содержит
параметры страницы, текста, таблиц, заголовков и альбомных схем.
Личные исходники не включены в репозиторий. Короткие отчеты используют
сквозные номера рисунков/таблиц и непрерывные разделы; курсовые/ВКР —
номера по главам и новые страницы для крупных структурных блоков.

Это учебный профиль на основе ГОСТ 7.32-2017 с явно описанными предпочтениями
автора репозитория. Для строгого нормоконтроля навык сверяет требования
задания и применимого стандарта; одинакового ГОСТа для всех предметов нет.

### Установка через Codex

Отправьте Codex:

```text
Используй skill-installer и установи навык reports из репозитория
https://github.com/BugLivesMatter/skills, путь внутри репозитория — reports.
```

Если доступен стандартный установщик навыков, его команда:

```text
python <путь-к-skill-installer>/scripts/install-skill-from-github.py --repo BugLivesMatter/skills --path reports
```

Для локальной установки скопируйте **всю папку reports** в
`$CODEX_HOME/skills/reports` (обычно `~/.codex/skills/reports`). Не копируйте
личную папку `reports/references`, если она есть в вашем локальном клоне.
Проверьте, что в папке назначения есть `SKILL.md`, `agents/openai.yaml` и `guides/`.
После установки используйте навык в следующем сообщении.
Если папка назначения уже существует, сначала сравните версии и сохраните
нужные локальные изменения.

### Пример запроса

```text
Используй $reports. Подготовь отчет по лабораторной работе по базам данных
по приложенному заданию и результатам. Нужен DOCX. Times New Roman 14,
включая таблицы, минимум разрывов страниц, без приложений.
Проверь оформление в свежем PDF перед выдачей DOCX.
```

Файлы с личными отчетами в `references/` и `ereferences/` на любом уровне
игнорируются Git. Публичные инструкции находятся в `reports/guides/`:
навык работает без доступа к личным примерам. Коммит и публикация на GitHub —
отдельные действия; наличие локального коммита не означает, что он отправлен.
